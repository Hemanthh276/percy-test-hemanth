License System Release Notes

Version 3.9.0 | Last updated January 12, 2025

These release notes describe the current status, validated platforms, and known issues for the Nimbus License System 3.6.0 release.

What's New

High-availability DLS clusters

Run two DLS instances as an active/active pair for resilient license serving.

Token-based client auth

Clients can now lease licenses using short-lived tokens.

Improved audit logging

Every lease and return is now recorded with a full audit trail.
