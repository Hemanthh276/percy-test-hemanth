Nimbus License System Documentation

Version 3.6.0 | Last updated April 6, 2026

Nimbus® License System is used to serve a pool of floating licenses to Nimbus licensed products. The Nimbus License System is configured with licenses obtained from the Nimbus Licensing Portal.
