Delegated License Service Online Help

Version 3.6.0 | Last updated April 6, 2026

Delegated License Service (DLS) is a component of Nimbus License System that serves licenses to licensed clients. A DLS instance is hosted on-premises or in a cloud environment at a location that is accessible from your private network, such as inside your data center or VPC.

Getting Started

Install a DLS Instance

Deploy a DLS virtual appliance or containerized instance in your environment.

Register the DLS Instance

Bind the instance to a license server on the Nimbus Licensing Portal.

Install a License Server

Create and install a license server on the DLS instance.

Configure a Client

Point licensed clients at the DLS instance to lease licenses.
